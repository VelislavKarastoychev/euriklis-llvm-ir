\chapter{Installation and Setup}

\begin{lstlisting}[style=ts]
npm install @euriklis/llvm-ir
\end{lstlisting}

Or with Bun:
\begin{lstlisting}[style=ts]
bun add @euriklis/llvm-ir
\end{lstlisting}

That's it. No native dependencies, no compilation step, no system LLVM installation required (though you'll want LLVM's \texttt{llc} compiler to generate binaries).
