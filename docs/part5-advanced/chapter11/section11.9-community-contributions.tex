\section{Community Contributions Welcome}

Possible paths forward:
\begin{itemize}[noitemsep]
  \item \textbf{Metal Shading Language generator}: Generate \texttt{.metal} source text (similar to how we generate \acr{LLVM} \acr{IR} text)
  \item \textbf{\acr{MPSGraph} bindings}: High-level TypeScript \acr{API} for Metal Performance Shaders
  \item \textbf{\acr{AIR} reverse-engineering}: Document the format (challenging, legal concerns)
  \item \textbf{Lobby Apple}: Request official \acr{AIR} documentation or \acr{LLVM} Metal backend
\end{itemize}

If you're interested in helping, see the repository's contribution guidelines.
