\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

This work investigates the theoretical foundations and practical implementation of programmatic \acr{LLVM} intermediate representation generation from TypeScript, with particular emphasis on heterogeneous computing architectures spanning both \acr{CPU}s and \acr{GPU}s. It presents the \texttt{@euriklis/llvm-ir} library as a case study in bridging high-level dynamic language ecosystems with low-level compilation infrastructure.

The research methodology employed integrates formal theoretical analysis with empirical case studies. While compiler theory and intermediate representation design demand rigorous mathematical formalization—including static single assignment form, control flow graphs, and type system semantics—the practical application of these concepts requires concrete instantiation. Consequently, each theoretical construct is accompanied by its corresponding implementation, demonstrating the translation from abstract specification to executable code generation.

The structure of this work reflects this dual perspective. Part~I establishes the theoretical foundations of \acr{LLVM} \acr{IR} and its formal syntax. Part~II develops a systematic methodology for code generation, examining the semantic mappings between TypeScript language constructs and their intermediate representation. Parts~III through~VI extend this analysis to cross-platform compilation, heterogeneous computing architectures, and complete compiler design. Throughout, the exposition maintains formal rigor while providing sufficient implementation detail to support reproducibility and further research.
