\section{Use Cases in the JavaScript Ecosystem}

\begin{enumerate}[noitemsep]
  \item \textbf{\acr{DSL} compilers}: Build domain-specific languages that compile to native code (query languages, shader languages, config languages)
  \item \textbf{\acr{JIT} compilers}: Runtime code generation for interpreters (JavaScript VMs, database query engines)
  \item \textbf{\acr{GPU} compute from Node.js}: Generate \acr{CUDA}/\acr{ROCm} kernels at runtime without writing C++ wrappers
  \item \textbf{WebAssembly optimization}: Generate optimized \acr{WASM} modules from high-level abstractions
  \item \textbf{Cross-compilation tools}: Build deployment toolchains that target multiple architectures from one codebase
\end{enumerate}
