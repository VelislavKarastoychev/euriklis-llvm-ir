\section{Summary}

\acr{LLVM} provides a universal compilation backend. By generating \acr{LLVM} \acr{IR} from TypeScript:
\begin{itemize}[noitemsep]
  \item You stay in the JavaScript ecosystem (familiar tools, npm, TypeScript types)
  \item You unlock native performance on CPUs and GPUs
  \item You avoid platform-specific build complexity
  \item You leverage decades of \acr{LLVM} optimization research
\end{itemize}

The rest of this handbook shows you how.
