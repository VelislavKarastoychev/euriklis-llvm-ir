\section{The Rise of Performance-Critical JavaScript}

JavaScript and TypeScript have evolved beyond web browsers. They now power:

\begin{itemize}[noitemsep]
  \item \textbf{Scientific computing}: TensorFlow.js, \acr{GPU}.js, numerical libraries
  \item \textbf{Machine learning}: Neural network training, inference engines
  \item \textbf{Computer graphics}: Three.js, Babylon.js, game engines
  \item \textbf{Data processing}: Stream processing, \acr{ETL} pipelines, analytics
  \item \textbf{Blockchain}: Smart contract VMs, cryptographic operations
\end{itemize}

These workloads hit JavaScript's performance ceiling. While V8, SpiderMonkey, and JavaScriptCore have excellent \acr{JIT} compilers, they cannot compete with ahead-of-time compiled, hardware-specific code for compute-intensive tasks.
