\section{Volatile Access}

Mark memory operations as \texttt{volatile} to prevent optimization:

\begin{lstlisting}[style=ts]
const load = new LoadInst({
  name: "val",
  type: i32,
  pointerType: ptr,
  pointer: "mmio_reg",
  align: 4,
  isVolatile: true  // Prevent optimization
});
// Generates: %val = load volatile i32, ptr %mmio_reg, align 4
\end{lstlisting}

Use cases:
\begin{itemize}[noitemsep]
  \item Memory-mapped I/O registers
  \item Signal handlers
  \item Multithreaded shared variables (prefer atomics instead)
\end{itemize}
